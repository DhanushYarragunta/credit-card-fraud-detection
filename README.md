# Credit Card Fraud Detection

This project focuses on detecting fraudulent credit card transactions using machine learning techniques.

## 📌 Project Overview
Credit card fraud detection is a critical problem in the financial industry. This notebook implements data preprocessing, exploratory data analysis, and machine learning models to classify transactions as fraudulent or legitimate.

## 📂 Files in This Repository
- `Credit_Card_Fraud_Detection.ipynb` — Main Jupyter Notebook
- `.gitignore` — Git ignore rules for large files and cache
